# PASSWORD GENERATOR
У генератора есть 2 варианта паролей
1. С дополнительными символами(некоторые из них выглядят странно, но гугл сказал, что они все используются)
2. Без дополнительных символов

Чтобы сгенерировать пароль - введите в консоль тип пароля (1 или 2), затем введите необходимую длину для вашего пароля

# TELEGRAM BOT @madk1dswagabot

# Идея для создания телеграм-ботов
Я бы хотел создать простые мини-игры через телеграм-ботов, чтобы ученики финашки могли играть друг с другом(и не только)
например создать игру, популярную сейчас в тик токе - шпион
через ссылку приглашать в игру несколько человек(от 4 до 12), придумать пул интересных слов, например по математическим терминам и через игру выбирать одного шпиона.
Каждый игрок будет по очереди печатать подсказки в чат, и эта подсказка будет приходить каждому участнику, через круг будет выбор угадать шпиона или сделать еще один круг
мало того, что это будет весело, так еще и будет обучать учеников некоторым терминам, которые с помощью игры будут легко запоминаться
